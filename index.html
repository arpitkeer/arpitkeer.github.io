🖥 Laptop / PC (Chrome/Edge)
1. Connect ESP32-H2 via USB cable
2. Open this page on localhost or HTTPS
3. Click Connect USB → select your COM port (COMx on Windows, /dev/ttyUSBx on Linux)
4. If no port shows: install CH340 or CP210x drivers for your ESP32 USB chip
5. Set baud rate to match your firmware (usually 115200)
📱 Android — No USB Serial Support!
Web Serial API is NOT available on Android. Options:

Option A — WiFi TCP bridge:
• Add WiFi to your ESP32-H2 sketch
• Create a TCP server on port 23 (telnet)
• Use Serial WiFi Terminal app on Android

Option B — Bluetooth Serial (BLE):
• Add BLE UART service to your firmware
• Use Serial Bluetooth Terminal app

Option C — Use a laptop (easiest!)
📊 Google Sheets Setup
1. Go to script.google.com → New project
2. Paste the Apps Script from "Show Apps Script" button
3. Click Deploy → New deployment → Web app
4. Set "Execute as: Me", "Who has access: Anyone"
5. Click Deploy → Copy the URL → Paste it in the Sheets URL field
6. First time: authorize the script with your Google account
