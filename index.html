Advanced features

Browser-only sync works best with a Google Apps Script web app endpoint. A plain static page cannot safely write to a private Sheet without some Google-side endpoint or OAuth flow.
Tip: this page must be opened in a secure context (HTTPS or localhost). Web Serial is available in modern Chrome on desktop, and Chrome on Android has support for USB-based serial workflows depending on the device and connection path. ([developer.chrome.com](https://developer.chrome.com/docs/capabilities/serial?utm_source=chatgpt.com)) For Google Sheets, client-side write access is normally done either through Google OAuth in the browser or via a Google Apps Script web app endpoint. ([developers.google.com](https://developers.google.com/workspace/sheets/api/quickstart/js?utm_source=chatgpt.com))
